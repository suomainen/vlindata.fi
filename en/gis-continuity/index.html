GIS continuity and preparedness

The map works even when the interface does not respond.

Municipal GIS services often rely on external interfaces. When a service or network connection goes down, the map is still needed – for example in building control, land use and during disruptions.

A local backup system keeps a local copy of the datasets the municipality has chosen, which can be used in the browser and in QGIS even during an outage.

Request a quote

How does it work?

  1. Datasets are selected

    Together we agree which datasets and which area the municipality needs to have available during a disruption.

  2. Retrieval and conversion

    The datasets are retrieved from the interfaces on a schedule and stored in local GeoPackage and MBTiles files.

  3. Local map

    The browser map uses the local data already during normal operation. The same datasets also open in QGIS.

  4. Monitoring

    The status of the sources and the local service is checked regularly, and events are compiled into a report.

What does the municipality get?

  • Deployment

    Defining the data sources, installation in the municipality's environment and instructions for users.

  • Maintenance

    Updates, follow-up of monitoring and changes when data sources change.

  • Support for preparedness

    A description of the solution to support the municipality's continuity planning and NIS2 and ISO 22301 assessment.

Background

The solution is based on open-source software such as GDAL, MapLibre and QGIS.

Suitability is always assessed with the municipality's own datasets and needs. Retrieving new data requires a connection to the source service, but data already stored remains available during an outage.
